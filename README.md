## junienet\.github\.io

Built with Eleventy and posts are written in Markdown.

## Directories

The main config file is `eleventy.config.js`

Files are deployed from `src` 

And is rendered to `_site` where it is loaded from.

Of which contains `content`, `deco` and `layouts`

### Source Directory

`content` is where all the writing goes to, mainly under `posts`

Additional tidbits will go under `stuff`

`deco` has the CSS stylesheet written in `styles.css` along with the web font files used in the website

`layouts` includes the reusable templates used for the website layout
